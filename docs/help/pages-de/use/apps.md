# Apps {#apps}

Fadenstack hat eigene Apps für andere Orte, an denen Sie arbeiten: den Desktop-Agenten, die Office-Add-ins, die Nextcloud-App und die Chrome-Erweiterung. Bietet Ihr Administrator eine an, zeigt die Seite **Apps**, wo Sie sie bekommen und wie Sie sie mit dem Server Ihrer Organisation verbinden.

## Die Seite öffnen {#open-the-page}

Öffnen Sie das Menü des Chats und wählen Sie **Apps**, oder rufen Sie `/apps` auf dem Server Ihrer Organisation auf. Die Seite listet nur die Apps, die Ihr Administrator angeboten hat.

## Was sie zeigt {#what-it-shows}

Für jede App:

- den Download;
- die neueste Version;
- das Ende ihres Supports;
- wie sie mit diesem Server verbunden wird, samt der Adresse des Servers.

## Eine App holen und verbinden {#get-an-app-and-connect-it}

1. Wählen Sie auf **Apps** den Download-Link der App.
2. Installieren Sie sie von der Seite aus, die sich öffnet.
3. Geben Sie in der App die Adresse des Servers ein, die auf **Apps** steht, falls sie danach fragt, und melden Sie sich mit Ihrem eigenen Konto an.

Möglicherweise hat Ihre IT-Abteilung die Adresse des Servers schon für Sie eingetragen, z. B. bei den Office-Add-ins und der Chrome-Erweiterung.

Bei der Nextcloud-App ist es anders: Die Administration Ihrer Nextcloud installiert sie für alle. Danach öffnen Sie Fadenstack in Nextcloud und melden sich an.

## Wohin die Downloads führen {#where-the-downloads-go}

Ein Download öffnet die Seite, auf der die App veröffentlicht ist: GitHub, den Chrome Web Store oder den Nextcloud-App-Store. Diese Seite sieht Ihre Adresse (IP), wie bei jedem Link. Der Link verrät ihr nicht, von welchem Server Sie kommen.
